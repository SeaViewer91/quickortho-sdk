# QuickOrtho SDK v0.2.0

> 릴리스: 2026-09-28

처리 결과를 **파이썬 변수로 바로 받아** 다른 라이브러리의 입력으로 쓸 수 있게 한 것이 핵심임.
OpenCV 함수처럼 결과를 여러 변수로 풀면 numpy 배열, 좌표 정보, 카메라 자세, 점군이 나옴.

## 설치

```bash
pip install https://github.com/SeaViewer91/quickortho-sdk/releases/download/v0.2.0/quickortho_sdk-0.2.0-py3-none-any.whl
```

## 새 기능

### 산출물을 변수로 받기

```python
image, transform, crs = project.process()            # (H, W, 4) uint8, affine.Affine, pyproj.CRS
cameras, points, crs = project.align()               # 카메라 자세 목록, 희소 점군
quicklook, coverage, transform, crs = qo.preview(...)
images, summary = qo.scan(folder)
image, transform, crs, gcps = project.refine()
```

- 결과 객체로 받으면 0.1.0과 같게 동작함
- `qo.read_orthomosaic()`, `qo.read_dsm()`, `qo.read_raster()`: 워크스페이스·파일에서 `(array, transform, crs)`로 읽기.
  `scale`(축소), `bounds`(지도 좌표 범위), `order`(RGBA·RGB·BGRA·BGR) 지원
- `CameraPose`: OpenCV 형식 `K`·`dist`·`R`·`t`·`rvec`·`P`, 사진측량 자세각 `opk`(ω, φ, κ), `project()`, `rays()`
- `Cameras`: 이름으로 찾기, `centers`, `opk`, `to_csv()`. `PointCloud`: `xyz`·`rgb`·`error`·`track_length`, `filter()`, `to_ply()`
- `Project.cameras()`, `points()`, `read_orthomosaic()`, `read_dsm()`
- 미리보기: `coverage.tif`(중복 매수·누락 GeoTIFF), 누락·촬영 범위 shapely 도형(`gaps()`, `footprints()`)

### 사진 좌표 ↔ 지도 좌표

- `Project.image_to_ground(image, uv, z=None)`: 원본 사진 좌표 → 지도 좌표 (DSM 또는 지정 높이 수평면과 교차)
- `Project.ground_to_image(image, xyz)`: 지도 좌표 → 사진 좌표

### 좌표계·격자·지형면

- `OrthoOptions(epsg=5186)`: 결과 좌표계 지정 (투영 좌표계)
- `OrthoOptions(bounds=..., grid_origin=..., gsd_m=...)`: 결과 범위·격자 고정. 시기별 결과가 화소 단위로 겹침
- `OrthoOptions(dsm="plane", dsm_z=...)`: 수평면으로 정사투영 (수면·평탄지)
- `OrthoOptions(dsm="dem.tif")`: 외부 DSM/DEM 사용. 좌표계 자동 재투영, 높이 기준 차이 자동 보정(`dsm_vertical_align`)
- 정사 모자이크 옵션은 워크스페이스에 저장되어 `refine()`의 재생성에도 쓰임

### 명령줄

- `--format auto|text|json`: 터미널이면 진행 막대·요약, 파이프면 JSON (기본 auto)
- `quickortho doctor`: 설치 환경 진단 (`qo.doctor()`)
- `quickortho export`: 카메라 CSV·JSON, 점군 PLY 내보내기
- `--epsg`, `--bounds`, `--grid-origin`, `--dsm`, `--dsm-z`, `--no-dsm-vertical-align`

## 호환성

- 0.1.0의 일반적인 사용 코드(함수 호출, 결과 속성 읽기)는 그대로 동작함
- `PreviewResult`의 필드 이름이 `quicklook_path`, `coverage_path`로 바뀜. 이전 이름 `quicklook`, `coverage`는 속성으로 남아 같은 경로를 돌려줌.
  다만 `PreviewResult`를 직접 만들거나 `dataclasses.replace()`·`asdict()`로 다루는 코드는 새 이름을 써야 함
- `PreviewResult.corners_lonlat`을 PNG 격자의 실제 경계로 계산하도록 고침 (이전에는 세로로 최대 한 칸 어긋날 수 있었음)
- GCP 보정으로 좌표계가 바뀌면 저장된 `bounds`·`grid_origin`·평면 `dsm_z`를 적용하지 않고 경고를 남김
- 명령줄 인자 오류(`export`에 출력 파일을 주지 않음 등)의 종료 코드를 2로 통일
- `report.json`에 `dsm.mode` 등 키가 추가됨 (`report_version`은 1 그대로). `preview.json`에 `bounds`, `outputs.coverage_tif` 추가
- serve 프로토콜 버전은 1 그대로
