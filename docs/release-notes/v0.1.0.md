# QuickOrtho SDK v0.1.0

첫 릴리스임. [QuickOrtho 데스크톱 앱](https://github.com/SeaViewer91/quick-ortho) v0.2.0의 처리 엔진을 분리해
웹 API·서버 프로그램·응용 프로그램에서 쓸 수 있는 Python SDK로 정리함.

## 설치

```bash
pip install https://github.com/SeaViewer91/quickortho-sdk/releases/download/v0.1.0/quickortho_sdk-0.1.0-py3-none-any.whl
```

wheel 하나로 macOS(14 이상, Apple Silicon)·Windows 10/11(x64)·Ubuntu 20.04 이상(x86_64), Python 3.10~3.14에 설치됨.
자세한 내용은 [설치 문서](https://github.com/SeaViewer91/quickortho-sdk/blob/main/docs/installation.md) 참고.

## 주요 내용

- **공개 API**: `Project`(create·open, scan, preview, align, orthomosaic, process, set_edits, refine, reset_refinement,
  info, tiepoint_stats, predict), 폴더 함수 `scan`·`preview`·`process`, 옵션·결과 객체, GCP·Mark·TiePoint, `load_gcps`
- **단계 분리**: 정렬(SfM)과 정사 모자이크 생성을 나눔. 정렬을 한 번 하면 GSD만 바꿔 정사 모자이크를 다시 만들 수 있음
- **진행 이벤트와 중단**: `on_event` 콜백, `CancelToken`, 표준 `logging`("quickortho" 로거)
- **예외 체계**: `QuickOrthoError`와 하위 예외 5종, 고정 오류 코드(`code`)
- **안전한 결과물 교체**: 정사 모자이크·DSM은 임시 파일에 쓴 뒤 교체함. 중단·실패해도 이전 결과가 유지됨
- **명령줄**: `quickortho`(`quickortho-engine` 별칭). `align`·`render` 명령 추가, `error` 이벤트에 `code`,
  serve·version에 프로토콜 버전(1)
- **정밀 보정**: GCP(국내 좌표계 포함)·수동 타이포인트·오차 큰 관측 정리 후 번들 조정 (데스크톱 앱 v0.2.0과 같은 알고리즘)
- **문서**: 설치, 빠른 시작, 핵심 개념, API 레퍼런스, 진행률과 중단, 정밀 보정, 결과물과 보고서, 명령줄, 성능, 문제 해결, 개발 참여
- **예제 6종**, **CI**: 세 OS × Python 3.10·3.14에서 합성 드론 영상으로 SfM → 정사 → GCP 보정 전체 시험

## 데스크톱 앱 엔진(v0.2.0)과의 차이

- 패키지 이름: `quickortho_engine` → `quickortho` (명령 `quickortho-engine`은 그대로 씀)
- `report.json`에 `report_version`(1) 추가. 그 밖의 필드는 같음
- 정렬 보고서를 `project/align_report.json`에 따로 저장함. 앱 v0.2.0이 만든 워크스페이스(`base_report.json`)도 열 수 있음
- serve `ready`·`version` 결과에 `protocol` 필드 추가, `error` 이벤트에 `code` 필드 추가 (기존 필드는 같음)
- `report.json`의 `timings_s.total_s`는 "정렬 + 마지막 정사 모자이크" 시간의 합임

## 알려진 한계

- 간이 DSM(희소 점군)이라 고층 건물 옆면이 보이고 경계가 겹칠 수 있음
- `CancelToken` 중단은 COLMAP 계산 구간(특징점 추출·매칭·SfM)이 끝난 뒤 반영됨. 즉시 중단은 serve 프로세스 종료로 함
- JPG만 지원, GPS 있는 영상 3장 이상 필요
- 검증 기종은 DJI Mavic 2 Pro. 실측 GCP 검증은 아직 하지 않음
